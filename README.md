# Exhibit site

The marketing site for [Exhibit](https://github.com/cdonohue/exhibit): static files in `public/`, served by the Worker `exhibit-site`.

The screenshots in `public/evidence/` are from real Exhibit runs on Cirrusflash, a fictional dashboard made for testing. Keep the site's claims to what runs have shown.

```sh
npm install
npm run dev      # local preview
npm run deploy
```
